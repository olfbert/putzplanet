# Putzplanet

> Ein Praktikant. Ein roter Knopf. 100.000 Teile Müll.

First-Person-Aufräumspiel fürs Handy. Am ersten Tag als Praktikant bei der MüllExpress Intergalaktisch GmbH drückst du den falschen Knopf – und 100.000 Teile Müll regnen auf **Blühonia**, den schönsten Ferienplaneten der Galaxis. Chef Dreckmann lässt dir einen rostigen Schredder da und fliegt davon. Mit dem Kaffee.

**Spielen:** https://olfbert.github.io/putzplanet/

- Kugelplanet mit Hügeln, Seen, Wäldern, Wiesen und Felsen – rundherum begehbar, ohne dass man die Wölbung merkt
- Aufheben, Fegen, Werfen; Schreddi 3000 zahlt pro Teil Münzen
- Shop: Behälter, Besen, Schuhe, Greifweite, Turbo, Roombas (mit Motor-, Tank- und Funk-Upgrades), Mini-Schredder
- Roombas lassen sich aufheben und woanders absetzen; ist ihr Gebiet leer, ziehen sie selbst zum nächsten Schredder mit Arbeit
- 32 Erfolge, Spielzeit-Timer, Funksprüche vom Chef
- 3 Speicherstände im Browser, Export/Import als Code
- Multiplayer: Menü → „Freunde einladen“, Code oder Link teilen (PeerJS/WebRTC, der Host speichert)

**Steuerung:** Handy – links ziehen laufen, rechts wischen umsehen, tippen aufheben. PC – WASD, Maus, E aufheben, F fegen, Q werfen, R Roomba absetzen, B Shop.

Natur-Modelle: [Quaternius – Stylized Nature MegaKit](https://quaternius.com) (CC0). Eine einzige HTML-Datei ohne Build-Schritt; three.js und PeerJS kommen vom CDN.
